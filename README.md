# 100DaysGame


## 📌 소개
이 프로젝트는 Node.js 기반으로 개발된 애플리케이션입니다. 아래의 가이드를 따라 의존성을 설치하고 실행할 수 있습니다.

## 📂 프로젝트 클론
```bash
git clone <repository_url>
cd <project_directory>
```

## 📦 의존성 설치
```bash
npm install
```

## ✍️ 수정할 부분
- node_server.js의 APP_DIR

## 🚀 애플리케이션 실행
### node_server.sh 를 이용한 백그라운드 실행 및 종료
```bash
bash node_server.sh start
bash node_server.sh stop
bash node_server.sh status
```

### 기본 실행 명령어
```bash
node app.js
```
